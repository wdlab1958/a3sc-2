AIMES

공장의 하루를
한 화면에 기록합니다

AIMES는 생산, 품질, 재고, 설비, 위생 관리를 한곳에서 기록하고 살펴보는 공장 운영 시스템입니다. 무엇을 언제 얼마나 만들었는지, 어느 원재료가 어느 제품이 되었는지가 남고, AI가 그 기록을 읽어 품질과 설비의 이상 조짐을 미리 알려 줍니다. 판단과 승인은 사람이 합니다.

Overview

기록은 흩어져 있고,
문제는 뒤늦게 보입니다

생산 일지는 종이에, 검사 결과는 엑셀에, 냉장고 온도는 벽에 붙은 점검표에 있습니다. 문제가 생기면 이 기록들을 사람이 하나씩 맞춰 봐야 합니다.

이 방식으로는 「이 제품에 어느 원재료가 들어갔는가」를 답하는 데 시간이 걸리고, 온도가 기준을 벗어난 사실도 점검 시간이 되어야 알게 됩니다. 식품을 다루는 공장이라면 위생 관리 기록을 빠짐없이 남기는 일 자체가 큰 부담입니다.

AIMES는 MES(제조실행시스템), 곧 공장에서 일어나는 일을 기록하고 지시하는 시스템입니다. 기준 제품인 AIMES AgriProcess는 농수산물 가공 공장을 대상으로 생산, 품질, 재고, 설비 보전, 이력추적, 저온 유통, 스마트팜 일곱 영역과 HACCP(식품 위생 관리 기준) 기록을 한 화면에 모읍니다. 그 위에서 AI가 기록을 읽고 이상 조짐을 먼저 알립니다.

쉽게 말하면

공장 전체가 함께 쓰는 하나의 업무 일지와 같습니다. 일지를 꼼꼼히 읽고 「여기를 한번 보십시오」 하고 짚어 주는 조수가 곁에 있습니다.

일지는 작업지시, 검사 결과, 온도 기록이고, 조수는 AI입니다. 조수는 짚어 줄 뿐이며, 조치를 정하고 기록을 확정하는 일은 담당자가 합니다.
흩어진 기록을한 화면으로

생산량, 합격률, 위생 관리 상태, 설비 상태를 대시보드 하나에서 봅니다. 현황은 수 초 간격으로 새로 고쳐집니다.

기준을 벗어나면바로 알림

가열 온도나 냉장 온도가 정해 둔 기준을 벗어나면 경고가 뜨고, 담당자가 조치 내용을 기록해야 다음으로 넘어갑니다.

문제가 생기면거슬러 추적

완제품 묶음에서 원재료 묶음까지 거슬러 올라가 어느 공정과 검사를 거쳤는지 확인합니다. 회수 범위를 좁히는 근거가 됩니다.

AI의 분석은공장 안에서

문장을 만드는 AI는 공장 안 서버에 설치한 모델을 씁니다. 기준 구성에서 생산 데이터는 외부 AI 서비스로 보내지 않습니다.

How it works

현장의 기록이 들어가면
경고와 보고가 나옵니다

작업자가 입력한 내용과 센서가 보낸 값이 들어가면, 여섯 단계를 거쳐 현황판과 경고, 추적 기록, 보고서가 됩니다. 기준을 벗어난 일의 조치와 승인은 사람이 맡습니다.

  1. 기록

    작업지시(무엇을 얼마나 만들라는 지시)를 등록하고, 원재료 입고와 검사 결과를 입력합니다. 원재료와 제품에는 LOT(같은 조건으로 들어오거나 만든 한 묶음)의 번호가 붙습니다.

    작업자 · 관리자
  2. 수집

    온도, 습도, 설비 진동 같은 센서 값을 받아 시간 순서로 쌓습니다. 현장 수집 장치는 통신이 끊기면 값을 모아 두었다가 다시 보냅니다.

    수집 장치 · 자동
  3. 감시

    CCP(중요관리점, 반드시 지켜야 하는 위생 관리 지점)의 값이 기준 안에 있는지 계속 확인하고, 통과·경고·이탈·센서 끊김으로 표시합니다.

    시스템 · 자동
  4. 예측

    예측 모델이 등급, 신선도, 미생물 증식, 설비 상태를 추정하고, 언어 모델이 그 결과와 현황을 한국어 문장으로 풀어 줍니다.

    예측 모델 · 로컬 LLM
  5. 조치

    이탈이 생기면 담당자에게 알림이 가고, 담당자는 시정조치(바로잡은 내용)를 기록합니다. 조치 완료는 관리자가 확인합니다.

    담당자 기록 · 관리자 승인
  6. 보고

    쌓인 기록이 일간·주간·월간 보고서와 통계 화면이 됩니다. 누가 무엇을 바꾸었는지는 감사 기록으로 남습니다.

    시스템 · 자동
시스템과 AI가 자동으로 처리사람이 입력하거나 승인
Features

공장의 일곱 영역을
같은 기록 위에서 봅니다

아래는 농수산물 가공용 기준 제품 AIMES AgriProcess에서 확인되는 기능입니다. 영역은 나뉘어 있어도 같은 LOT 번호로 서로 이어집니다.

위생 관리(HACCP) 감시

HACCP은 식품에 해가 될 수 있는 요소를 공정마다 미리 정해 관리하는 기준입니다. AIMES는 공정 흐름도 위에 관리 지점을 표시하고, 지점마다 현재 값과 기준을 나란히 보여 줍니다. 기준을 벗어나면 그 사실과 조치가 함께 기록으로 남습니다.

  • 금속 검출, 가열 살균, 냉각 같은 관리 지점의 상태 표시
  • 이탈 시 담당자 알림과 시정조치 기록
  • 센서 값의 추이로 이탈 가능성을 미리 경고
  • 온도와 시간에 따른 미생물 증식 예측 곡선

생산 관리와 계획

작업지시를 등록하고 진행 상태를 따라갑니다. 생산 계획은 제출과 승인을 거쳐 실행됩니다.

  • 작업지시 등록, 시작, 완료, 취소
  • 라인별 가동 상태와 OEE(설비 종합 효율)
  • 주간·월간 계획과 계획 대비 실적 비교

품질 검사와 등급 선별

검사 값을 입력하면 기준에 따라 합격 여부가 판정됩니다. 원재료 사진은 AI가 등급을 추정합니다.

  • 원재료·공정·완제품 검사와 결함 유형 관리
  • 특·상·보통·하·불합격 다섯 등급 추정
  • AI 판정은 담당자가 다시 판정할 수 있음

재고와 저온 유통

창고 구역별 재고와 유통기한을 관리하고, 콜드체인(저온을 유지한 채 옮기는 유통 과정)의 온도를 따라갑니다.

  • 산지·운송·공장·물류·매장 다섯 구간 온도 기록
  • 온도 이탈 구간 표시와 남은 신선도 추정
  • 안전재고 미달과 유통기한 임박 확인

이력추적과 LOT 추적

원재료가 어디서 왔고 어느 공정을 거쳐 어느 제품이 되었는지를 양방향으로 따라갑니다.

  • 원산지, 생산자, 인증 정보 조회
  • 완제품에서 원재료로 거슬러 가는 역추적
  • LOT별 품질 검사 이력과 회수 명령 기록

설비 보전

설비 상태와 정비 계획, 고장 기록을 한곳에서 관리합니다. 고장 나기 전에 정비 시점을 잡도록 돕습니다.

  • 예방·예지·사후·긴급 정비 계획
  • 설비 건강 점수(0~100) 추정
  • 점수가 낮은 설비를 우선 정비 대상으로 제안

AI 어시스턴트

「오늘 생산 현황은」처럼 말로 물으면 AI가 기록을 조회해 답합니다. 조회만 할 수 있고 기록을 바꾸지는 못합니다.

  • 현황을 요약한 인사이트와 권고
  • 일간·주간·월간 보고서 초안 작성
  • 결과마다 「로컬 AI」 또는 「규칙 기반」 출처 표시

정기 보고서일간·주간·월간 생산, 품질, 설비 요약. PDF와 문서 파일로 저장초안을 담당자가 검토해 내부 보고에 씁니다.
감사 기록누가 언제 어떤 기록을 만들고 바꾸었는지. 추가만 되고 고쳐 쓰지 않는 기록기록의 신뢰성을 뒷받침합니다.

예측 모델 8종은 현재 물리 법칙을 바탕으로 만든 합성 데이터로 학습한 상태입니다. 현장의 실제 데이터로 다시 학습하기 전에는 예측값을 참고 자료로만 써야 하며, 정확도 수치는 이 화면에 싣지 않았습니다. AIMES의 기록은 HACCP 인증이나 심사 결과를 대신하지 않습니다.

확장 구성의 화면 가운데 상당수는 아직 예시 데이터로 표시되며, 실제 데이터와의 연결은 산업별로 진행 중입니다. 예측 모델은 합성 데이터로 학습한 상태이고, 현장 장비와 잇는 계층은 설계와 골격 단계입니다. 농수산물 가공 외의 산업은 도입 전에 필요한 기능의 구현 여부를 함께 확인합니다.

Principle

AI가 답하지 못하면
지어내지 않는다

공장의 숫자는 사람이 믿고 움직이는 근거입니다. 그럴듯하게 만든 숫자는 없는 것보다 해롭습니다.

AIMES는 언어 모델이 응답하지 않으면 미리 정해 둔 규칙으로 분석을 대신하고, 어느 쪽이 만든 결과인지 화면에 표시합니다. 센서가 끊긴 관리 지점은 「통과」가 아니라 「오프라인」으로 보여 줍니다. 아래는 검증 결과와 현재의 한계입니다.

CASE · 기준 제품의 형식 검증

동시에 누른 버튼까지 따져 보았습니다

에이쓰리시큐리티의 One Cycle 형식 검증을 작업지시 처리에 적용했습니다. 두 사람이 같은 작업지시를 동시에 시작·완료·취소하는 모든 순서를 모델 검사로 따져 결함 3건을 찾았습니다.

2건 수정완제품 LOT가 두 번 만들어지는 문제와 완료된 작업이 취소되는 문제를 고쳤습니다. 동시에 시작하면 원재료가 두 번 출고될 수 있는 1건은 수정 방식을 정하는 중입니다. 정해 둔 범위 안에서 확인한 결과입니다.
LIMITS · 현재의 한계
  1. 입력하지 않은 일은 기록되지 않습니다센서가 없는 공정은 작업자의 입력에 의존합니다. 기록의 품질은 현장의 입력 습관을 따라갑니다.
  2. 센서 연결에는 현장 작업이 필요합니다장비마다 통신 방식이 달라 도입 단계에서 연결 범위를 정합니다. 소형 현장 게이트웨이는 실물 장비에 올리기 전의 선행 개발 단계입니다.
  3. 예측은 참고 자료입니다현재 모델은 합성 데이터로 학습했습니다. 현장 데이터로 다시 학습하고 사람이 결과를 확인해야 합니다.
  4. 외부 알림은 설정 후 동작합니다화면 알림은 기본으로 표시되지만, 이메일과 문자 발송은 발송 수단을 연결해야 합니다.

Glossary

쉽게 풀어 드립니다

이 화면에 나오는 용어를 전공자가 아니어도 읽을 수 있게 정리했습니다.

MESManufacturing Execution System · 제조실행시스템
공장에서 무엇을 언제 얼마나 만들지 지시하고, 실제로 일어난 일을 기록하는 시스템입니다. 회계와 주문을 다루는 ERP와 현장 설비 사이를 잇습니다.
HACCP식품안전관리인증기준 · 해썹
식품에 해가 될 수 있는 요소를 공정마다 미리 찾아 관리하는 위생 관리 기준입니다. 관리한 사실을 기록으로 남겨야 합니다.
CCPCritical Control Point · 중요관리점
여기서 놓치면 안전을 되돌릴 수 없는 공정 지점입니다. 가열 온도나 금속 검출이 대표적이며, 지점마다 지켜야 할 기준이 있습니다.
LOT로트 · 묶음 번호
같은 날 같은 조건으로 들어오거나 만든 한 묶음입니다. 번호를 붙여 두면 문제가 생겼을 때 그 묶음만 가려낼 수 있습니다.
이력추적 · 역추적Traceability
원재료가 어느 제품이 되었는지 따라가는 일이 이력추적이고, 완제품에서 원재료로 거슬러 가는 일이 역추적입니다.
콜드체인Cold Chain · 저온 유통
신선 식품을 산지에서 매장까지 낮은 온도로 유지하며 옮기는 과정입니다. 한 구간이라도 온도가 오르면 품질이 떨어집니다.
작업지시Work Order
어느 라인에서 어떤 제품을 얼마나 만들라는 지시서입니다. 등록, 진행, 완료 같은 상태를 가집니다.
시정조치Corrective Action
기준을 벗어난 일이 생겼을 때 바로잡은 내용과 재발을 막기 위한 조치를 적은 기록입니다.
OEEOverall Equipment Effectiveness · 설비 종합 효율
설비가 얼마나 제 몫을 했는지를 가동 시간, 속도, 양품 비율을 곱해 나타낸 지표입니다.
예지 보전Predictive Maintenance
고장이 난 뒤에 고치는 것이 아니라, 설비 데이터로 고장 조짐을 읽어 미리 정비하는 방식입니다.
로컬 LLM · 온프레미스Local LLM · On-premise
문장을 이해하고 만드는 AI 모델과 시스템을 외부 클라우드가 아닌 조직 안의 서버에 설치해 쓰는 방식입니다.
합성 데이터 · 모델 검사Synthetic Data · Model Checking
합성 데이터는 실제 측정값 대신 규칙에 따라 만들어 낸 학습용 데이터입니다. 모델 검사는 일이 일어날 수 있는 순서를 빠짐없이 따져 결함을 찾는 검증 방법입니다.

자주 묻는 질문

우리 공장의 생산 데이터가 회사 밖으로 나갑니까?

기준 제품인 AIMES AgriProcess는 공장 안 서버에 설치하는 구성이며, 문장을 만드는 AI도 같은 곳에 설치한 로컬 모델만 호출합니다. 이 구성에서 생산 데이터는 외부 AI 서비스로 전송되지 않습니다. 다만 이메일·문자 알림을 켜면 알림 내용이 해당 발송 서비스를 거칩니다. 확장 구성인 AIMES-Eleven에는 외부 AI 서비스를 선택해 쓰는 설정이 있으며, 켜지 않으면 호출되지 않습니다.

사람은 무엇을 해야 합니까?

기록을 입력하고, 판단하고, 승인하는 일입니다. 작업지시와 검사 결과는 작업자가 입력합니다. 기준을 벗어난 일이 생기면 담당자가 시정조치를 기록하고 관리자가 확인합니다. 생산 계획도 제출과 승인을 거칩니다. AI는 살펴볼 곳을 짚어 주지만 조치를 대신하지 않습니다.

AI가 틀리면 어떻게 됩니까?

AI의 결과는 참고 자료로 다루도록 설계되어 있습니다. 등급 추정은 담당자가 다시 판정할 수 있고, 결과마다 로컬 AI가 만든 것인지 규칙으로 만든 것인지가 표시됩니다. AI 어시스턴트는 기록을 조회만 할 수 있어 틀린 답이 기록을 바꾸지는 못합니다. 현재 예측 모델은 합성 데이터로 학습했으므로, 현장 데이터로 다시 학습하기 전에는 예측값만으로 출하나 폐기를 결정해서는 안 됩니다.

AI 서버가 멈추면 시스템도 멈춥니까?

멈추지 않습니다. 생산, 품질, 재고, 위생 관리 기록과 감시는 AI와 관계없이 동작합니다. 언어 모델이 응답하지 않으면 인사이트와 보고서는 정해 둔 규칙으로 만들어지고, 화면에 「규칙 기반」으로 표시됩니다.

지금 쓰는 ERP나 설비를 바꿔야 합니까?

바꾸는 것을 전제로 하지 않습니다. AIMES는 현장의 실행 기록을 맡고, 센서 값은 널리 쓰이는 통신 방식(MQTT)으로 받습니다. 다만 설비와 기존 시스템은 공장마다 달라서, 어디까지 연결할지는 도입 단계에서 범위를 정하고 연결 작업을 해야 합니다. 센서가 없는 공정은 입력 화면으로 시작할 수 있습니다.

농수산물 가공이 아닌 공장도 쓸 수 있습니까?

확장 구성 AIMES-Eleven이 열한 개 산업을 다룹니다. 다만 구현 정도가 고르지 않습니다. 식품·화장품·제약·전자·2차 전지는 화면과 기능 점검을 마쳤고, 자동차 부품·섬유는 일부 기능을 보완 중이며, 금속·의료기기·화학은 부분 구현 상태입니다. 여러 화면이 아직 예시 데이터로 표시되므로, 필요한 기능이 실제 데이터로 동작하는지를 도입 전에 함께 확인합니다.

AIMES는 무엇을 보증하고, 무엇은 보증하지 않습니까?

보증하는 것은 기록의 일관성과 출처의 표시입니다. 입력된 기록이 LOT 번호로 이어지고, 변경은 감사 기록에 남으며, AI 결과에는 만든 방식이 표시됩니다. 제품의 안전, HACCP 인증의 통과, 예측의 정확도는 보증하지 않습니다. 형식 검증의 결과도 작업지시 처리라는 정해 둔 범위에 한정됩니다.

공장의 기록, 지금 어디에 흩어져 있습니까?

관리할 공정과 센서 연결 범위, 필요한 기록 양식을 함께 정해 드립니다.
